# ثبت قیمت دستی نقرهٔ ۹۹۹.۹ در زیوتو از توکنیکو

این سند قرارداد API ارسال قیمت فروش هر گرم نقرهٔ ۹۹۹.۹ از توکنیکو به زیوتو است. توکنیکو پس از هر تغییر قیمت دستی، قیمت جدید را به ریال ارسال می‌کند.

## نشانی و احراز هویت

در نمونه‌های زیر، `api.example.com` را با دامنهٔ بک‌اند زیوتو جایگزین کنید. کلید مشترک را جداگانه و از مسیر امن دریافت کنید؛ آن را در کد یا لاگ درخواست‌ها ثبت نکنید.

| مورد | مقدار |
| --- | --- |
| روش | `POST` |
| مسیر | `/api/tokeniko/pricing/silver9999-manual` |
| نوع محتوا | `application/json` |
| هدر پاسخ JSON | `Accept: application/json` |
| هدر احراز هویت | `X-Tokeniko-Secret: your_shared_secret_here` |
| محدودیت درخواست | ۱۰ درخواست در دقیقه به ازای IP |

## بدنهٔ درخواست

فیلد `price_rial` قیمت **فروش یک گرم نقرهٔ ۹۹۹.۹ به ریال** است. آن را به‌صورت عدد صحیح مثبت، حداکثر `999999999999999`، ارسال کنید. فیلد خرید یا قیمت محصول ارسال نمی‌شود.

```json
{
  "price_rial": 5130000
}
```

برای مثال، `5130000` ریال در فیلد قیمت دستی زیوتو به‌صورت `513000` تومان ذخیره می‌شود. تبدیل ریال به تومان بدون گرد کردن انجام می‌شود؛ `5130001` ریال به `513000.1` تومان تبدیل می‌شود.

## پاسخ‌ها

در پاسخ موفق، `price_rial` قیمت دریافت‌شده و `updated` نتیجهٔ تغییر مقدار ذخیره‌شده است.

```json
{
  "price_rial": 5130000,
  "updated": true
}
```

| کد HTTP | معنا | اقدام توکنیکو |
| --- | --- | --- |
| `200` | قیمت پذیرفته شد؛ `updated: false` یعنی مقدار از قبل یکسان بوده است | درخواست را موفق ثبت کنید |
| `401` | کلید مشترک ارسال نشده یا نامعتبر است | هدر و کلید را بررسی کنید |
| `422` | `price_rial` وجود ندارد یا مقدار آن معتبر نیست | بدنهٔ درخواست را اصلاح کنید |
| `429` | محدودیت تعداد درخواست | با تأخیر دوباره تلاش کنید |
| `503` | کلید API در سرور زیوتو تنظیم نشده است | به تیم زیوتو اطلاع دهید |

ارسال دوبارهٔ همان قیمت مجاز است: پاسخ `200` با `updated: false` برمی‌گردد و رکورد تاریخچهٔ تکراری ایجاد نمی‌شود. برای خطای شبکه یا پاسخ `429` و `503`، ارسال را با فاصلهٔ زمانی افزایشی تکرار کنید.

## نمونهٔ درخواست

این دستور یک قیمت نمونه را ارسال می‌کند. دامنه و کلید را پیش از اجرا جایگزین کنید.

```bash
curl --request POST 'https://api.example.com/api/tokeniko/pricing/silver9999-manual' \
  --header 'Content-Type: application/json' \
  --header 'Accept: application/json' \
  --header 'X-Tokeniko-Secret: your_shared_secret_here' \
  --data '{"price_rial":5130000}'
```

## اثر درخواست در زیوتو

زیوتو همان مقدار «قیمت دستی فروش نقرهٔ ۹۹۹.۹» را که در `/admin/pricing/manual-prices` وجود دارد تغییر می‌دهد و کش تابلو را مانند ذخیره از همان فرم پاک می‌کند. قیمت محصولات طبق فرآیند فعلی زیوتو به‌روزرسانی می‌شود؛ این API فرآیند محاسبهٔ فوری جداگانه‌ای اجرا نمی‌کند.

هر تغییر واقعی در `/admin/pricing/audit-logs` با نام عامل «توکنیکو (API)»، IP درخواست و مقدار قبلی و جدید ثبت می‌شود. اگر «تابلوی مستقیم توکنیکو» در زیوتو فعال باشد، قیمت دستی و تاریخچه همچنان ثبت می‌شوند، اما قیمت مستقیم تابلو با این مقدار جایگزین نمی‌شود.
