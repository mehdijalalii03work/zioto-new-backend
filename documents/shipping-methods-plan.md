| کد | روش | توضیح                                                         |
|----|------|---------------------------------------------------------------|
| `in_store_pickup` | **تحویل حضوری** | مراجعه مشتری به دفنر شرکت                                     |

| فیلد | نوع | توضیحات |
|------|-----|---------|

### ۳.۲. جدول `shipping_rates`

| فیلد | نوع | توضیحات |

| `max_weight` | decimal(10,3) nullable | حداکثر وزن (گرم) |

| `max_cart_total` | decimal(12,0) nullable | حداکثر مبلغ سبد خرید |
| `base_rate` | decimal(12,0) | هزینه پایه (ریال) |
| `per_kg_rate` | decimal(12,0) nullable | هزینه اضافه به ازای هر کیلوگرم |
| `free_shipping_min` | decimal(12,0) nullable | آستانه رایگان شدن ارسال |
| `estimated_days_min` | tinyint nullable | حداقل روز تخمینی تحویل |
| `estimated_days_max` | tinyint nullable | حداکثر روز تخمینی تحویل |
| `timestamps` | | |

## ۴. مدل‌ها و ارتباطات

```
ShippingMethod
  ├── hasMany → ShippingRate
  ├── hasMany → OrderShipping
  └── scope: active() - متدهای فعال

ShippingRate
  ├── belongsTo → ShippingMethod
  ├── belongsTo → Province (nullable)
  ├── belongsTo → City (nullable)
  └── scope: forProvince($id), forCity($id)

Order
  └── hasOne → OrderShipping

OrderShipping
  ├── belongsTo → Order
  └── belongsTo → ShippingMethod
```

## ۵. منطق قیمت‌گذاری هر روش

### ۵.۱. تحویل حضوری (`in_store_pickup`)

| مشخصه | مقدار |
|-------|-------|
| هزینه | **رایگان** |
| تعرفه | `rate_type: flat` با `base_rate: 0` |
| تخمین زمان | `estimated_days_min: 0, estimated_days_max: 1` |
| نمایش | آدرس و ساعات کاری دفتر شرکت (از تنظیمات ادمین) |

- کاربر صرفاً تأیید می‌کند که برای تحویل حضوری به دفتر شرکت مراجعه می‌کند
- آدرس و ساعات کاری دفتر در صفحه نمایش داده می‌شود (قابل تنظیم از تنظیمات ادمین)
- امکان تعیین تاریخ مراجعه (اختیاری)
- **قابلیت غیرفعال‌سازی از داشبورد:** کافی است `is_active = false` در `shipping_methods`

### ۵.۲. تیپاکس (`tipax`)

| مشخصه | مقدار |
|-------|-------|
| هزینه | **تعرفه کشوری بر اساس وزن** |
| تعرفه | `rate_type: weight` + `per_kg_rate` برای اضافه وزن |
| تخمین زمان | ۲-۵ روز کاری بسته به استان |

- وزن محموله از مجموع وزن محصولات در سبد خرید محاسبه می‌شود
- تعرفه پایه + هزینه به ازای هر کیلوگرم اضافه
- قابلیت تنظیم تعرفه مجزا برای استان‌های دور

**مثال رکوردهای تعرفه:**
```
rate_type=weight, min_weight=0, max_weight=200, base_rate=150,000, per_kg_rate=0
rate_type=weight, min_weight=201, max_weight=1000, base_rate=200,000, per_kg_rate=50,000
```

### ۵.۳. پیک شهری (`peyk`)

| مشخصه | مقدار |
|-------|-------|
| هزینه | **تعرفه منطقه‌ای درون‌شهری** |
| تعرفه | `rate_type: city` یا `rate_type: weight` محدود به تهران |
| تخمین زمان | ۲-۶ ساعت |

- فعلاً فقط برای تهران (قابل توسعه به شهرهای دیگر)
- منطقه‌بندی: مرکز / شمال / جنوب / شرق / غرب / کرج
- تعرفه بر اساس منطقه مقصد و وزن مرسوله

**پیشنهاد منطقه‌بندی پیک تهران:**
```
منطقه ۱ (مرکز): ۱۲۰,۰۰۰ ریال
منطقه ۲ (شمال): ۱۵۰,۰۰۰ ریال
منطقه ۳ (غرب): ۱۳۰,۰۰۰ ریال
منطقه ۴ (شرق): ۱۴۰,۰۰۰ ریال
منطقه ۵ (جنوب): ۱۲۰,۰۰۰ ریال
منطقه ۶ (کرج): ۲۰۰,۰۰۰ ریال
```

### ۵.۴. پست فلزات گرانبها (`post_precious`)

| مشخصه | مقدار |
|-------|-------|
| هزینه | **تعرفه استانی + بیمه** |
| تعرفه | `rate_type: province` + درصد بیمه |
| تخمین زمان | ۳-۷ روز کاری |

- قیمت پایه برای هر استان متفاوت است
- بیمه امانات گرانبها (درصدی از ارزش محموله)
- نیاز به بسته‌بندی ویژه
- ثبت کد رهگیری پست پیشتاز یا سفارشی

**مثال تعرفه استانی:**
```
استان تهران: base_rate=200,000
استان البرز: base_rate=200,000
استان اصفهان: base_rate=250,000
استان خراسان رضوی: base_rate=300,000
استان هرمزگان: base_rate=350,000
...
```

**هزینه بیمه:**
```
ارزش محموله ≤ ۵۰ میلیون: ۰.۵٪
ارزش محموله > ۵۰ میلیون: ۱٪
```

## ۶. API‌ها

### ۶.۱. روش‌های ارسال (عمومی)

| متد | مسیر | توضیحات |
|-----|------|---------|
| GET | `/api/shipping/methods` | لیست روش‌های ارسال فعال + شرایط و هزینه |
| GET | `/api/shipping/methods/{id}` | جزئیات یک روش |
| POST | `/api/shipping/calculate` | محاسبه هزینه ارسال برای سبد فعلی + آدرس مقصد |

### ۶.۲. محاسبه هزینه (Endpoint اصلی)

**Request:**
```json
{
  "shipping_method_id": 1,
  "province_id": 8,
  "city_id": 191,
  "cart_items": [
    {"product_id": 1, "quantity": 2, "weight": 10.5},
    {"product_id": 3, "quantity": 1, "weight": 25.0}
  ],
  "cart_total": 25000000
}
```

**Response:**
```json
{
  "shipping_cost": 350000,
  "estimated_min_days": 3,
  "estimated_max_days": 5,
  "has_insurance": true,
  "insurance_cost": 125000,
  "total_shipping_cost": 475000,
  "breakdown": {
    "base_rate": 300000,
    "weight_surcharge": 50000,
    "insurance": 125000
  }
}
```

### ۶.۳. مدیریت در ادمین (Filament)

| مسیر | توضیحات |
|------|---------|
| `/admin/shipping/methods` | CRUD روش‌های ارسال + تغییر وضعیت فعال/غیرفعال |
| `/admin/shipping/rates` | مدیریت تعرفه‌ها |
| `/admin/shipping/settings` | تنظیمات کلی (نرخ بیمه، آدرس دفتر برای تحویل حضوری) |

## ۷. جریان کاربری در تسویه حساب

### گام ۱: انتخاب آدرس
- کاربر آدرس خود را انتخاب یا ثبت می‌کند

### گام ۲: انتخاب روش ارسال
- پس از انتخاب آدرس، API روش‌های ارسال فعال را برمی‌گرداند
- کاربر روش را انتخاب می‌کند
- هزینه به صورت خودکار محاسبه و نمایش داده می‌شود
- برای تحویل حضوری: آدرس و ساعات کاری دفتر شرکت نمایش داده می‌شود

### گام ۳: نمایش در خلاصه سفارش
```
آدرس ارسال: تهران، میدان ونک، خیابان ولیعصر...
روش ارسال: پست فلزات گرانبها
هزینه ارسال: ۳۵۰,۰۰۰ تومان
تخمین تحویل: ۳ تا ۵ روز کاری
```

### گام ۴: ذخیره در سفارش
- هنگام ثبت سفارش، `order_shippings` همراه با snapshot ذخیره می‌شود

## ۹. امنیت و محدودیت‌ها

- **ارسال فقط به آدرس تأیید شده:** برای سفارش‌های بالای ۱۰۰ میلیون، آدرس باید با اطلاعات شاهکار تطابق داشته باشد
- **بیمه اجباری برای پست فلزات گرانبها:** تمام مرسولات بالای ۲۰ میلیون بیمه شوند
- **محدودیت روش ارسال بر اساس مبلغ:** سفارش‌های بالای ۲۰۰ میلیون فقط تحویل حضوری یا پست مخصوص با بیمه کامل
- **رهگیری اجباری:** تیپاکس و پست نیاز به شماره رهگیری دارند که در ادمین ثبت می‌شود

## ۱۰. تحویل حضوری — گزینه غیرفعال‌سازی از داشبورد

ادمین می‌تواند به سادگی با تغییر یک toggle در Filament روش تحویل حضوری را فعال یا غیرفعال کند:

```
ShippingMethod Resource
  ├── List → ستون is_active با toggle (BooleanColumn)
  ├── Edit → Switch: is_active
  └── Effect → صفحه تسویه این روش را نمایش نمی‌دهد
```

**در فرانت‌اند:**
```js
// API /api/shipping/methods فقط روش‌های is_active=true را برمی‌گرداند
const methods = await fetch('/api/shipping/methods');
// اگر is_pickup=false از فیلتر خارج شد، تحویل حضوری نمایش داده نمی‌شود
```

## ۱۳. دیاگرام جریان

```
تسویه حساب
  ├── کاربر آدرس را انتخاب می‌کند
  ├── GET /api/shipping/methods (بر اساس استان/شهر مقصد)
  ├── نمایش روش‌های فعال:
  │     ├── ● تحویل حضوری → نمایش آدرس دفتر شرکت
  │     ├── ● تیپاکس → نمایش هزینه محاسبه‌شده
  │     ├── ● پیک شهری → نمایش هزینه محاسبه‌شده
  │     └── ● پست فلزات گرانبها → نمایش هزینه + بیمه
  │
  └── ثبت سفارش
        ├── INSERT INTO orders
        ├── INSERT INTO order_shippings
        └── نمایش پیام موفقیت + روش ارسال + تخمین زمان
```
