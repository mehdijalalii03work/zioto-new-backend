# پلن ایجاد ماژول پرداخت (Payment Module)

## خلاصه
ایجاد ماژول کامل پرداخت شامل Migration، Model، و Filament Resource برای مدیریت تراکنش‌های پرداخت.

## فیلدهای جدول payments

| فیلد | نوع | توضیح |
|------|------|-------|
| id | bigint | کلید اصلی |
| user_id | bigint, nullable | FK → users |
| order_id | bigint, nullable | FK → orders |
| transaction_id | string(50), unique | شماره مرجع تراکنش |
| amount | decimal(12,0) | مبلغ پرداختی (ریال) |
| payment_method | string(20), nullable | روش پرداخت: online, card_to_card, installment |
| status | string(20), default 'pending' | وضعیت: pending, successful, failed, refunded |
| gateway | string(50), nullable | نام درگاه پرداخت |
| gateway_response | json, nullable | پاسخ خام درگاه |
| description | text, nullable | توضیحات |
| paid_at | datetime, nullable | تاریخ پرداخت موفق |
| timestamps | - | created_at, updated_at |
| soft_deletes | - | حذف نرم |

## Fix: Import Path در Payment Model
فایل `Modules/Payment/app/Models/Payment.php` دارای import اشتباه `App\Models\Order` هست.
باید به `Modules\Order\Models\Order` تغییر کنه.

**تغییر مورد نیاز:**
```php
// قبل:
use App\Models\Order;
use App\Models\User;

// بعد:
use App\Models\User;
use Modules\Order\Models\Order;
```
