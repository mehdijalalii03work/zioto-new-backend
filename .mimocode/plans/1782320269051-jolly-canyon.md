# اضافه کردن کتابخانه پرونده‌ها (Media Library) به Filament

## خلاصه
اضافه کردن پلاگین رسمی `filament/spatie-laravel-media-library-plugin` برای مدیریت فایل‌ها مشابه وردپرس. فقط برای محتوای جدید (بدون مهاجرت فایل‌های موجود).

## مراحل اجرا

### 1. نصب پکیج‌ها
```bash
composer require filament/spatie-laravel-media-library-plugin:"^5.0" -W
composer require spatie/laravel-medialibrary -W
```

### 2. انتشار و اجرای migration
```bash
php artisan vendor:publish --provider="Spatie\MediaLibrary\MediaLibraryServiceProvider" --tag="medialibrary-migrations"
php artisan migrate
```

### 3. آماده‌سازی مدل‌ها برای Media Library
فایل‌هایی که باید تغییر کنن:

**`Modules/Blog/app/Models/BlogPost.php`**
- اضافه کردن `InteractsWithMedia` trait
- تعریف media collections: `featured-image`, `content-images`
- حذف فیلد `image` ساده (اختیاری - می‌تونیم نگه‌داریم برای سازگاری)

**`Modules/Product/app/Models/Product.php`**
- اضافه کردن `InteractsWithMedia` trait
- تعریف media collections: `product-images`, `gallery`

**`Modules/Product/app/Models/ProductImage.php`**
- اضافه کردن `InteractsWithMedia` trait (اختیاری - اگر بخوایم تصاویر جداگانه مدیریت بشن)

**`app/Models/Brand.php`**
- اضافه کردن `InteractsWithMedia` trait
- تعریف media collection: `logo`

### 4. به‌روزرسانی فرم‌های Filament

**`app/Filament/Resources/BlogPosts/Schemas/BlogPostForm.php`**
- تغییر `FileUpload::make('image')` به `SpatieMediaLibraryFileUpload::make('featured_image')->collection('featured-image')`
- اضافه کردن `SpatieMediaLibraryFileUpload` برای تصاویر محتوا (اختیاری)

**`app/Filament/Resources/Products/Schemas/ProductForm.php`**
- تغییر `FileUpload::make('image_path')` به `SpatieMediaLibraryFileUpload::make('image_path')->collection('product-images')`
- به‌روزرسانی Repeater برای استفاده از media library

**`app/Filament/Resources/BrandResource/Pages/EditBrand.php`** (یا فرم Brand)
- اضافه کردن `SpatieMediaLibraryFileUpload` برای آپلود لوگو

### 5. اضافه کردن Table Columns و Infolist Entries
**`app/Filament/Resources/BlogPosts/Tables/BlogPostsTable.php`**
- اضافه کردن `SpatieMediaLibraryImageColumn::make('featured_image')->collection('featured-image')`

**`app/Filament/Resources/Products/Tables/ProductsTable.php`**
- اضافه کردن `SpatieMediaLibraryImageColumn::make('product_image')->collection('product-images')`

### 6. پیکربندی (اختیاری)
- اضافه کردن دیسک `media` در `config/filesystems.php` (اگر بخوایم فایل‌های media جداگانه ذخیره بشن)
- پیکربندی `config/media-library.php` (بعد از انتشار)

- `Modules/Product/app/Models/Product.php`

- `app/Filament/Resources/Products/Schemas/ProductForm.php`
- `app/Filament/Resources/BlogPosts/Tables/BlogPostsTable.php`
- `app/Filament/Resources/Products/Tables/ProductsTable.php`
- `config/filesystems.php`

## بررسی نهایی
1. اجرای `php artisan migrate`
2. اجرای `vendor/bin/pint --dirty --format agent`
3. بررسی آپلود فایل در فرم‌های Blog Post و Product
4. بررسی نمایش تصاویر در جدول‌ها
5. اجرای تست‌ها: `php artisan test --compact`
