# Plan: Fix Slug Routes Not Working

## Problem
`/product/[slug]` and `/blog/[slug]` pages show "This page could not be found" after renaming `[id]` to `[slug]` directories while the dev server was running.

## Root Cause
Next.js dev server caches the route structure. Renaming dynamic route directories (`[id]` → `[slug]`) while the server is running doesn't get picked up until restart.

## Fix
1. Kill the running Next.js dev server
2. Delete `.next` build cache
3. Restart the dev server

## Verification
- `http://localhost:3000/product/zioto-gold-bar-1g-995` should load
- `http://localhost:3000/blog/برنامه-ریزی-برای-آینده-کودکان` should load
