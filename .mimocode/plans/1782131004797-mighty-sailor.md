# بازطراحی بصری داشبورد حسابفا

## هدف
بهبود بصری صفحه داشبورد حسابفا + اضافه کردن بخش لاگ سریع فعالیت‌ها

## فایل‌های تغییر

1. `resources/views/filament/pages/hesabfa-dashboard.blade.php` - تغییر اصلی
2. `app/Filament/Pages/Hesabfa/HesabfaDashboard.php` - اضافه کردن مетод getRecentActivity()

---

## تغییرات blade view

### ۱. بهبود کارت‌های آمار
- اضافه کردن hover effect با `hover:shadow-md hover:-translate-y-0.5 transition-all duration-200`
- اضافه کردن gradient subtle در بالای هر کارت (خط رنگی نازک با `before:` pseudo-element)
- بهبود فضای داخلی و آیکون‌ها
- اضافه کردن درصد پیشرفت (synced/total) به صورت نوار پیشرفت کوچک زیر عدد

### ۲. بهبود بخش وضعیت اتصال
- اضافه کردن animation برای آیکون وضعیت (pulse برای موفق، shake برای خطا)
- بهبود layout دکمه sync با اضافه کردن loading state بهتر

### ۳. اضافه کردن بخش لاگ سریع (Activity Timeline)
- Timeline ساده با آخرین ۱۰ فعالیت همگام‌سازی
- هر آیتم: آیکون وضعیت (موفق/خطا)، نوع sync، شماره سفارش، زمان
- استفاده از خط عمودی برای اتصال آیتم‌ها (standard timeline pattern)
- Badge رنگی برای نوع sync و وضعیت

### ۴. بهبود بخش جدول خطاها
- اضافه کردن hover state بهتر برای ردیف‌ها
- بهبود فضای خالی (empty state) با آیکون و متن توضیحی

## تغییرات PHP class

### مетод جدید: `getRecentActivity()`
```php
public function getRecentActivity(): array
{
    return HesabfaSyncLog::with('order')
        ->latest()
        ->limit(10)
        ->get()
        ->toArray();
}
```

## کلاس‌های Tailwind کلیدی برای بهبود بصری

### Stat Cards Hover
```
hover:shadow-md hover:-translate-y-0.5 transition-all duration-200
```

```
relative flex gap-4 pb-6
```
### Timeline Line
```
absolute left-[15px] top-8 h-full w-0.5 bg-gray-200
```

```
inline-flex items-center rounded-full px-2 py-0.5 text-xs font-medium bg-emerald-50 text-emerald-700 ring-1 ring-inset ring-emerald-600/20
```
