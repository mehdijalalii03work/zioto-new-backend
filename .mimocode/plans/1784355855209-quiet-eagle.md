# Plan: Tokeniko Direct Price Fetching + Tapsi Shop Integration

## Context

WordPress site fetches prices directly from `https://apigateway.tokeniko.com/shop/api/Category/getPrices` (public API, no auth) and syncs them to Tapsi Shop. The Laravel project currently uses tablo-based price calculation. We need both modes switchable via `PRICING_MODE` env var.

---

## 1. Config + ENV

**New file: `config/pricing.php`**
```php
return [
    'mode' => env('PRICING_MODE', 'dynamic'), // 'direct' or 'dynamic'
];
```

**New file: `config/tapsi.php`**
```php
return [
    'auth_token' => env('TAPSI_AUTH_TOKEN', ''),
    'auth_name' => env('TAPSI_AUTH_NAME', 'zioto_sync_node'),
    'base_url' => env('TAPSI_API_BASE_URL', 'https://vendorgw.tapsi.shop/web/hub/vendors/v1'),
    'markup_below_50m' => (int) env('TAPSI_MARKUP_BELOW_50M', 2),
    'markup_above_50m' => (int) env('TAPSI_MARKUP_ABOVE_50M', 1),
];
```

**Modify: `.env` + `.env.example`** — Add:
```
PRICING_MODE=direct
TAPSI_AUTH_TOKEN=
TAPSI_AUTH_NAME=zioto_sync_node
TAPSI_API_BASE_URL=https://vendorgw.tapsi.shop/web/hub/vendors/v1
```

## 2. Database Migration

**New: `database/migrations/xxxx_add_tokeniko_and_tapsi_fields_to_products.php`**

Add to `products` table:
- `tokeniko_sku` (string, nullable) — maps to tokeniko API `Name` (e.g. `zioto-gold-bar-1gram-995`)
- `tapsi_product_id` (string, nullable) — the real SKU sent to Tapsi (e.g. `ZGB5-0001-0`)

**Modify: `Modules/Product/app/Models/Product.php`** — Add to `$fillable`: `tokeniko_sku`, `tapsi_product_id`

---

## 3. `TokenikoShopService` — Fetch direct prices

**New: `app/Services/TokenikoShopService.php`**

- Calls `https://apigateway.tokeniko.com/shop/api/Category/getPrices`
- Parses response: `Model[].Name` → price (SellPrice / 10 for toman)
- Returns map: `[tokeniko_sku => price_in_toman]`
- Caches result for 60s

---

## 4. `TapsiShopService` — Send to Tapsi Shop

**New: `app/Services/TapsiShopService.php`**

Mirrors WordPress behavior:
- `sendBatchToTapsiShop(array $products)` — PUT to `/web/hub/vendors/v1/products`
- `refreshToken(string $expiredToken)` — POST to `/web/hub/vendors/v1/refresh-token`
- Auth header: `TapsiShop.Hub.Authorization`
- Tapsi price markup: +2% below 50M Toman, +1% above 50M Toman
- Auto-refresh token on 401
- Stock = 0 when emergency kill-switch is active
- Token stored in `tapsi_shop_outgoing_auth_token` setting (using `Setting` model)

---

## 5. `SyncTokenikoPrices` Command

**New: `app/Console/Commands/Tokeniko/SyncTokenikoPrices.php`**

Signature: `tokeniko:sync-direct`

Flow:
1. Fetch prices from `TokenikoShopService`
2. Query products where `tokeniko_sku` is not null
3. Update `price` column in DB
4. Build Tapsi payload with markup + stock
5. Send batch via `TapsiShopService`
6. Broadcast `PriceBoardUpdated` + `ProductsUpdated` events (Reverb)
7. Clear product caches
